## 知識

- [臨] 大型任務的交接品質決定成敗：一句話的 handoff prompt 等於把下個 session 丟進黑暗裡。6 區塊標準建立後跨 session 連貫性有質的提升
- [臨] 預設「不會有人另開 session 處理你留下的尾巴」——這個心態比任何 SOP 都重要

## 行動

- 跨 session 任務評估時，交接文件品質列為必檢項
